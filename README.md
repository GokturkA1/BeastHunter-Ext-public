# Wolvesville Room Bot

Bu Chrome uzantısı, [Wolvesville](https://wolvesville.com/) oyununda otomatik olarak oda açmanıza yardımcı olmak için tasarlanmıştır.

**Sürüm:** 1.0.0

## Açıklama

Uzantı, belirli ayarlarla Wolvesville'de otomatik olarak oyun odaları oluşturma sürecini basitleştirir.

## Kurulum

Uzantıyı Chrome tarayıcınıza iki farklı yöntemle yükleyebilirsiniz:

### Yöntem 1: Paketlenmemiş Uzantıyı Yükleme (`dist` klasörü)

Bu yöntem genellikle geliştirme veya test amaçlıdır.

1.  Size sağlanan `dist` klasörünü bilgisayarınıza indirin ve sıkıştırılmış dosyadan çıkarın (unzip yapın).
2.  Chrome tarayıcınızı açın ve adres çubuğuna `chrome://extensions/` yazarak Uzantılar sayfasına gidin.
3.  Sayfanın sağ üst köşesindeki "Geliştirici modu" seçeneğini etkinleştirin.
4.  Sol üstte beliren "Paketlenmemiş öğe yükle" düğmesine tıklayın.
5.  Açılan pencerede, 1. adımda çıkardığınız `dist` klasörünü seçin ve "Klasör Seç" düğmesine tıklayın.
6.  Uzantı listenizde "Wolvesville Room Bot" görünecektir.

### Yöntem 2: CRX Paketini Yükleme (İmzalanmış Sürüm)

Bu yöntem, uzantının imzalanmış sürümünü yüklemek içindir.

1.  Size sağlanan `.crx` uzantılı dosyayı bilgisayarınıza indirin.
2.  Chrome tarayıcınızı açın ve adres çubuğuna `chrome://extensions/` yazarak Uzantılar sayfasına gidin.
3.  İndirdiğiniz `.crx` dosyasını bu Uzantılar sayfasına sürükleyip bırakın.
4.  Chrome, uzantıyı eklemek isteyip istemediğinizi soran bir uyarı gösterecektir. "Uzantıyı ekle" düğmesine tıklayarak onaylayın.

**Not:** Chrome, bilinmeyen kaynaklardan uzantı yükleme konusunda uyarılar gösterebilir. Yalnızca güvendiğiniz kaynaklardan gelen `.crx` dosyalarını yükleyin.

## Kullanım

1.  Uzantı başarıyla yüklendikten sonra, Chrome araç çubuğunuzdaki yapboz parçası simgesine tıklayarak uzantılar listesini açın ve "Wolvesville Room Bot" uzantısını bulun. İsterseniz, kolay erişim için uzantıyı sabitleyebilirsiniz (pin simgesi).
2.  Wolvesville web sitesine (`https://*.wolvesville.com/`) gidin.
3.  Araç çubuğundaki "Wolvesville Room Bot" simgesine tıklayın.
4.  Açılan penceredeki talimatları izleyerek bot ayarlarını yapılandırın ve başlatın.

## Sorumluluk Reddi

*   Bot veya otomasyon araçlarının kullanımı, Wolvesville'in Hizmet Şartları'nı ihlal edebilir.
*   Bu uzantıyı kullanmanın riski tamamen size aittir. Uzantının kullanımından kaynaklanabilecek herhangi bir hesap askıya alma, ceza veya diğer olumsuz sonuçlardan geliştirici sorumlu tutulamaz.
